Политика конфиденциальности

Threads Autopilot Pro · Последнее обновление: 14 ноября 2026 г.

Кто отвечает за данные

Владелец приложения Threads Autopilot Pro: German. По вопросам обработки данных: germansee78@gmail.com.

Какие данные обрабатывает приложение

  • Имя пользователя Threads и идентификатор аккаунта.
  • Токен доступа Threads после того, как пользователь разрешит OAuth-доступ.
  • Созданные в приложении черновики, расписание публикаций и результаты работы функций приложения.
  • Адрес, порт, имя пользователя и пароль прокси, если пользователь добавил прокси.
  • Идентификатор и настройки Local Bridge, необходимые для связи приложения с Safarier на Mac.

Где хранятся данные

В локальном режиме база данных приложения хранится на Mac пользователя. Токены Threads и учётные данные прокси шифруются при хранении. Сессии, cookies и данные браузера остаются в локальном профиле Safarier на Mac. Local Bridge не извлекает cookies, пароли Threads, одноразовые коды или токены из браузера.

С кем данные передаются

  • Meta / Threads: приложение обменивается данными с API Meta для OAuth и разрешённых пользователем функций Threads.
  • Прокси-провайдер: сетевые запросы, направленные через выбранный прокси, проходят через инфраструктуру этого провайдера.
  • Провайдер ИИ: если пользователь настроил OpenAI или OpenRouter и запускает генерацию, соответствующие запросы и переданный контекст отправляются выбранному провайдеру для обработки.

Данные не продаются. Приложение не передаёт данные указанным сервисам для иных целей, кроме выполнения выбранных пользователем функций.

Срок хранения и удаление

Локальные данные хранятся, пока они нужны для работы приложения или пока пользователь не удалит их из него. Удаление карточки аккаунта удаляет её запись из базы Autopilot, но не удаляет созданный профиль Safarier и его локальную браузерную сессию; такой профиль нужно удалить отдельно средствами Safarier.

Безопасность

Приложение шифрует токены Threads и пароли прокси в локальной базе. Пользователь отвечает за защиту своего Mac, учётных записей Meta, файлов конфигурации и доступов к прокси.
